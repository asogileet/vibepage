# 《免費寶物大冒險：肥宅爸爸與兩個小太陽》
![170a39a3-1285-498b-9c44-753e7f9d1f4d.png](https://freetu-9ra.pages.dev/api/cfile/AgACAgUAAxkDAAMWaRNiStKfx5lUHSsnNX003wVZKeYAAkoLaxuD5aBUbJZQ4dwirYkBAAMCAAN5AAM2BA)
從前從前，有一位肥宅工程師爸爸。
他不是王子，也不是超級英雄，
但他有一個 圓圓的肚子 和 滿滿的愛。

爸爸最喜歡的東西叫做——
免費資源！！
（聽起來有點普通，可是爸爸覺得那就像寶藏💎）

有一天，爸爸看到一個「零度大哥哥」在網路上說：
「嘿～這裡有好多免費的魔法工具，你可以拿去做自己的小島！」

爸爸眼睛發亮：
「小島？我可以為我們家建一座小島嗎？」

於是爸爸開始了他的「部落格小島建造冒險」🏝️

爸爸一邊寫程式、一邊架網站、還一邊喝咖啡，
看起來就像一隻認真又胖胖的貓咪 🐈‍⬛。

可是啊……

爸爸不是為了自己。

是為了兩個小太陽：
宸宸 和 云云 ✨

爸爸心裡想：

「有些話，我說得不一定好。
但我想讓妳們以後長大、心情亂亂、世界有點吵時，
只要回到小島，就能看到爸爸留給你們的光。」

不是命令。不是期待。
只是陪伴。

慢慢看。不用懂。
爸爸會一直等。

🎶 然後，迎來了一件重要的事！

宸宸要直笛比賽了 🎼
原本爸爸以為自己不能去，但因為颱風延期了。

那一天來臨前，
爸爸既開心、又緊張得像水煮蛋在滾水裡跳：

「我會不會讓宸宸覺得丟臉呀…
我是那個肚子圓圓、不太帥的爸爸耶…」

但爸爸還是想去。

因為：

🫶 「當妳抬頭看台下時，我希望妳能看到我。」
🫶 「不管妳吹得好不好，我都會為妳拍手。」
🫶 「因為我是妳的爸爸。」

而云云呢？
爸爸會說：

「妳的時候，我也會到。
爸爸的心很大，很大，很大，
所以可以同時裝下你們兩個。」
